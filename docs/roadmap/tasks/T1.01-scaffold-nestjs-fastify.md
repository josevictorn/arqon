## Objetivo
Projeto NestJS mínimo rodando sobre Fastify, com TypeScript estrito, pnpm, path aliases e um endpoint `GET /health/live`, pronto para receber o tooling das próximas tasks.

## Escopo
- `package.json` com `packageManager` (pnpm via Corepack), `engines.node`, versões **exatas** (sem `^`) conforme ADR-0003.
- `.nvmrc` / `.node-version`.
- `tsconfig.json` + `tsconfig.build.json`: `strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `exactOptionalPropertyTypes` (avaliar), `emitDecoratorMetadata`, `experimentalDecorators`.
- Path aliases: `@/shared/*`, `@/modules/*`, `@/integrations/*`, `@test/*`.
- Build com SWC (`@nestjs/cli` + `swc`) e `nest-cli.json`.
- `src/main.ts` com `FastifyAdapter`, `enableShutdownHooks`, porta via `process.env.PORT` (o env validado vem na T3.01).
- `src/app.module.ts` + um `HealthController` mínimo (`GET /health/live` → `{ status: 'ok' }`), colocado provisoriamente em `src/shared/infra/http/health/`.
- Esqueleto de pastas vazias com `.gitkeep`: `src/shared/{core,contracts,application,infra}`, `src/integrations`, `src/modules`, `test/`.
- Scripts: `dev`, `build`, `start`, `typecheck` (`tsc --noEmit`), `verify` (por ora = `typecheck`; as próximas tasks estendem).
- `.gitignore`, `.editorconfig`.

## Fora de escopo
- Lint/format (T1.02), testes (T1.03), Docker (T1.06), validação de env (T3.01), Helmet/CORS/filtros (T3.02), Swagger/Scalar (T3.04).

## Critérios de aceite
- [ ] `pnpm install && pnpm build` sem warnings de peer dependency relevantes.
- [ ] `pnpm dev` sobe e `curl localhost:3000/health/live` retorna `200 {"status":"ok"}`.
- [ ] `pnpm typecheck` passa; um import via alias `@/shared/...` resolve no build e no dev.
- [ ] Nenhuma dependência do Express (`@nestjs/platform-express`) instalada.
- [ ] Versões fixadas batem com o ADR-0003.

## Verificação
```bash
pnpm install --frozen-lockfile
pnpm build && pnpm typecheck
pnpm dev &   # depois:
curl -s -o /dev/null -w "%{http_code}" localhost:3000/health/live   # 200
pnpm why @nestjs/platform-express   # vazio
```

## Notas / riscos
- O `nest new` gera Express + Jest + ESLint + Prettier. Prefira criar manualmente ou remover tudo isso.
- Path aliases precisam funcionar também no Vitest (T1.03) e no SWC: centralize em `tsconfig.json`.
