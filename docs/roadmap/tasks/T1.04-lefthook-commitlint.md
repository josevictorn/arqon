## Objetivo
Git hooks automáticos que impedem commits fora do padrão e pushes que quebram testes.

## Contexto para ler (e só isso)
- [AGENTS.md](../../../AGENTS.md)
- [11-code-quality.md](../../architecture/11-code-quality.md) (seção Lefthook)

## Escopo
- `lefthook` como devDependency, instalado no `prepare`.
- `lefthook.yml`:
  - `pre-commit` (paralelo): `biome check --write --staged` (re-stage dos arquivos corrigidos) + `tsc --noEmit`.
  - `commit-msg`: validar Conventional Commits (`@commitlint/cli` + `@commitlint/config-conventional`, ou alternativa leve) com os scopes permitidos: `iam`, `tenancy`, `billing`, `notifications`, `audit`, `shared`, `infra`, `integrations`, `docs`, `deps`, `ci`.
  - `pre-push`: `vitest related --run` sobre os arquivos alterados + `pnpm arch:check` (quando a T1.05 existir; deixe a linha preparada).

## Fora de escopo
- CI (T1.07).

## Critérios de aceite
- [x] `git commit -m "bad message"` é rejeitado; `git commit -m "chore(infra): test"` é aceito.
- [x] Um arquivo mal formatado é corrigido automaticamente no commit.
- [x] O hook de pre-push roda testes relacionados.

## Verificação
```bash
pnpm lefthook run pre-commit
echo "bad" | pnpm commitlint   # falha
```
