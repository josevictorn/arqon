## Objetivo
Todo PR é validado automaticamente com as mesmas checagens locais. Essa é a rede de segurança que permite revisar PRs de IA com confiança.

## Escopo
- `.github/workflows/ci.yml` com:
  - Job `verify`: checkout, setup de pnpm + Node (versão do `.nvmrc`), cache do pnpm, `pnpm install --frozen-lockfile`, `pnpm verify` (lint + typecheck + arch:check + test:unit).
  - Job `integration` (depois de `verify`): services ou compose `core` (+ `messaging` quando houver testes que precisem), roda `test:int` e `test:e2e`. Pode iniciar sem testes; deve passar vazio.
- `concurrency` para cancelar runs antigos do mesmo PR.
- (Opcional) Renovate ou Dependabot com agrupamento por ecossistema.

## Fora de escopo
- Deploy, build de imagem, release.

## Critérios de aceite
- [ ] Um PR com erro de lint, tipo ou arquitetura falha no CI.
- [ ] Tempo do job `verify` abaixo de 3 min com cache.

> Os dois critérios só podem ser confirmados no GitHub (ver "Verificação"). Validado localmente: `actionlint` sem erros; `test/infra/ci-workflow.spec.ts` falha se o `verify` deixar de rodar `pnpm verify` ou `--frozen-lockfile`; os passos do job `integration` (`infra:up` → `test:int` → `test:e2e`) passam com o compose `core` (~12 s até healthy).

## Verificação
- Abrir um PR de teste com uma violação proposital e confirmar a falha; depois remover.
